A retrieval-augmented chatbot that answers questions about the DLSU practicum from official documents. BEAT-BIT

A TinyML classifier that reads heart signals from a pulse sensor and classifies them on an ESP32-C3. The challenge was fitting a useful model into a few hundred kilobytes and keeping latency low enough to feel instant.

  • ESP32-C3
  • MAX30102
  • TinyML
  • Signal processing

Bayad Log

Small merchants who get paid by GCash screenshot end up with a camera roll full of receipts. Bayad Log reads each screenshot with OCR, records it in a ledger, and flags repeated reference numbers so the same payment can't be counted twice.

  • JavaScript
  • Tesseract.js
  • HTML / CSS
